Lobby Final prefab (by jiwon)

How to use
- After importing, drag Assets/LobbyPrefab/Prefabs/LobbyFinal into the Hierarchy.
  It is placed with all materials already applied.

Notes
- Made for URP projects (materials use URP/Lit). Source project: Unity 2022.3 + URP 14.
- Position and rotation are not included (it is placed at the origin). Move it wherever you need.
- Textures are high-quality JPGs to keep the package small (resolution is still 2048).
  Unity re-compresses textures for the game anyway, so there is no visible difference.
- Keep the .unitypackage file in a folder whose path has only English letters before importing.

Contents
- Models/LobbyFinal.fbx       : the lobby model
- Materials/              : 14 URP/Lit materials
- Textures/<part>/        : BaseColor, Normal, AO, Height, Metallic (+ Emissive for ExitDoor)
- Prefabs/LobbyFinal.prefab   : the model with every material assigned
